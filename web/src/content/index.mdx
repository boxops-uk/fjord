Fjord DB stores **facts**: small typed records like *`Crc32` is declared in `Crc32.cs` at
line 7*. You describe the shape of your facts once, write them in, and seal the database.
After that it never changes, and the result is a directory you can copy anywhere and serve
from as many processes as you like.

You query it in **sigla**, a small typed language. Fjord was built to be a **code index**:
files, declarations, references, the build graph. That is the data behind *go to
definition* and *find all references*.

## How it works

**Facts live in predicates.** A predicate is Fjord's word for a table. Part of each fact is
the **key**, which is indexed and is what queries match on. A fact may also carry a
**value**: extra data read only when a query asks for it.

**A database is built once, then frozen.** Create it against a schema, write facts, run
`finish`. From then on it is read-only. Every build produces a fresh database, the way you
rebuild an artifact rather than patching it.

**Queries can pause.** A query runs one row at a time and can stop part-way, hand back a few
bytes, and resume from exactly there later. Paging holds nothing open, and a different
process can serve the next page.

## Why read-only

- Every query sees one stable version of the data, with no locking.
- A paused query costs a few bytes, not an open connection.
- Writers never conflict, so ingestion runs in parallel.
- The database is a directory. `tar` it, copy it, serve it anywhere.

## A schema, a query, and the rows

A schema names your predicates and says what each holds:

```schema
schema demo {
  predicate Person : string
  predicate Knows  : { from : Person, to : Person }
  predicate Age    : { person : Person } -> int
}
```

A query is the shape you want back, `where`, and what to match:

```sigla
{a = X, b = Y} where demo.Knows {from = X, to = Y}
```

Rows come back in the same language:

```sigla
{a = demo.Person#1, b = demo.Person#2}
```

`demo.Person#1` is an **id**, because `Knows` points at two `Person` facts rather than
containing them. Ask for references to be expanded and you get the people:

```sigla
{a = "ada", b = "grace"}
```
